# Learning OpenGL

This repository documents my journey through exploring and learning OpenGL. It contains code samples, experiments, and projects that I have worked on while diving into the world of OpenGL programming.

## About

OpenGL (Open Graphics Library) is a cross-platform, hardware-accelerated API for rendering 2D and 3D vector graphics. This repository serves as a personal learning log and a collection of resources and code to understand OpenGL concepts better. 

## Technologies Used

The primary technologies used in this repository are:

- **C++**: For implementing OpenGL programs and managing graphical operations.
- **C**: For lower-level operations and compatibility with certain OpenGL libraries.
